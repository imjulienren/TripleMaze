# 约 100 枚箭头版 30 关

当前正式数据已替换到 `Resources/Levels/level_01.json` 至 `level_30.json`，保留图片主题与关卡编号。

- 每关 102–114 枚箭头，平均 108.5 枚。通过适配网格尺寸和稍长的路径减少过密分段，继续填满轮廓，而不是删除箭头挖空图片。
- 平均有效格点覆盖率约 99.60%，最低约 98.63%。图片主题不变，实际难度继续主要由出口和遮挡关系决定。
- 相近的深浅色先按大色系归并，再分配真正的消除编号。颜色类别最多五种，少色图片不强行补色。保留绿、蓝、紫等明显色系差异，避免合并后变成灰色；同一大色系的近似色不再分开占用消除类别。
- 同色数量和收集槽容量仍在生成时配平，每关配方保留完整可移出序列。

`30关清单.csv` 记录数量、颜色类别、覆盖率和遮挡参考分数；对应 `.recipe.json` 可以在生成器内继续编辑。上一版密铺数据保存在 `Backups/DenseCampaign30_before_balanced_20261025`，原密铺配方仍在 `Docs/DenseCampaign30`。

## 本轮运行表现调整

失败页统一显示三个空星，不论失败原因或剩余生命；仅胜利页播放两侧烟花及其音效。

每次新启动默认第 1 关，不读写关卡进度。Unity 工具栏仍能在播放时跳关；停止时手动选关，只覆盖下一次启动，消费后自动回到默认第 1 关。WebGL 构建不包含该编辑器覆盖行为。

棋盘背景格点从开局箭头的占格集合构建，图案外和内部空洞没有格点。集合不随箭头移除而丢失。通关后先用 0.45 秒恢复全图视角，再用 2.6 秒将格点铺开为原图配色的小方块，并逐渐浮现完整原图；完整原图停留 1.6 秒后进入结算页。

当前 30 关和配方均嵌入了对应的透明 PNG 原图。新导入图片生成的关卡也会自动保存底图（最长边最多 1024 像素），关卡 JSON 和配方可以独立携带图片。没有底图的手绘或旧关卡使用箭头配色形成方格图案。此次修改只检查运行代码和编辑器代码的编译，不自动运行或验收游戏效果；网页版本需要重新导出 WebGL。
