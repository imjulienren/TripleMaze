# TripleMaze 小型 Demo

## 当前实现

基础循环：点击无阻挡箭头，箭头沿自身折线滑出，进入七格收集槽；同色任意三枚自动消除，三消先于槽满判定。收集槽满失败，棋盘和收集槽同时清空胜利。误点被挡箭头不扣生命，无计时限制。

包含首页、游戏页、胜负结果弹层、重试、下一关、首页进度保存。游戏页支持点击、放大缩小、放大后拖动，以及双指缩放。已加入圆角箭头、按压回弹、沿线滑出、曲线入槽、三枚聚合、粒子反馈、分层音效、低音量音乐和撤回。视觉与关卡改版细节见 `Docs/体验打磨.md`。

## 打开与运行

- Unity 2022.3.62f3 打开本工程。
- 打开 `Assets/Scenes/TripleMaze.unity`，点击 Play。
- 如场景尚未创建，选择 `TripleMaze > 创建并打开 Demo 场景`。
- 关卡工具：`TripleMaze > 关卡编辑器`。
- 交付目标为手机浏览器 WebGL，由用户后续导出。网页默认分辨率为 720 × 1280。
- 游戏内容固定 9:16 竖屏，窗口变宽只增加外侧留白，整体等比缩放；手机安全区参与整体适配。
- 编辑器菜单 `TripleMaze > 手机竖屏预览 720x1280` 可切回手机预览。尚未进行浏览器真机验证。

## 编辑器操作

1. 打开现有 `Assets/TripleMaze/Resources/Levels/level_01.json`，或新建。
2. 绘制工具逐点点击。第一个点是头部，后续点是箭身的转折点，仅支持正交折线。Enter 完成，Esc 取消。
3. 选择工具点击箭头，可以设置六种颜色、反转头尾和删除。
4. 移动工具拖动箭头，中键平移画布，滚轮缩放；支持撤销、重做。
5. 校验检查越界、重叠、自交、非法折线、每色数量是否为三的倍数。求解最多搜索 25,000 个状态，区分无解与预算耗尽。
6. 保存为 JSON，然后试玩当前关卡。试玩不必先覆盖正式关卡。

只移植了静态箭头编辑工作流，未引入原项目的动态关卡、怪物、道具、管道、电梯、机关锁、捆绑箭头、热更新、广告或框架依赖。支持读取 ArrowSmash 正式 JSON 的 `levelConfig` 包装及 `initialSegments`、`colorDisplayIndex`、`points` 数据；特殊机关数据不会导入，因此应仅导入普通关卡并重新校验。

## 复用来源与取舍

- ArrowSmash：只读参考 `/Users/julienren/unity-arrow-smash/ArrowSmash`，未修改源项目。沿用首点头部、角点折线、整数占格、头部前方遮挡判定和静态网格编辑工作流。原核心依赖主题、视图、DOTween、框架和多个机关模块，因此在本工程实现独立的轻量适配，而非整套复制脚本。
- 20 关地图来自 ArrowSmash 的 `Bundles/Levels` 与 `Bundles/LevelsHot` 普通静态地图。只裁去既有可移出序列开头的一部分箭头，再重新配色，前四关按 3、6、9、12 枚递进，第四关引入四色形成槽位压力，后续逐步增加到 51 枚和五色。每关来源、数量、颜色数和可重放通关序列见 `Docs/source-levels.json`。
- Amaze GO：优先复用灯泡、导航、音量、星星、箭头卡片图标与音效，位于 `Assets/TripleMaze/Resources/Polish`。面板用 UGUI 圆角网格，避免九宫格变形。第一版原始提取素材仍保留在 UI、Audio 文件夹。新资源映射见 `Docs/polish-sources.json`。没有导入 Amaze GO 的关卡或逻辑。
- ArrowSmash `PathSmoother.cs` 已直接复用并调整命名空间，按压缩放与释放回弹参考其 AmButtonScaleEffect。
- 中文字体：Google Fonts 官方 Noto Sans SC，SIL Open Font License，许可证随 `Resources/Fonts/OFL.txt` 保存。原始来源 https://github.com/google/fonts/tree/main/ofl/notosanssc ，已将变量字体固定为 500 字重，以供 Unity 2022 使用。

## 代码结构

- `PuzzleModel.cs`：数据、占格、遮挡、三消、胜负、校验和有界求解，不依赖场景对象。
- `ArrowBoardGraphic.cs`：UGUI 网格箭头绘制、触摸命中、折线路径滑出、视图缩放拖动。
- `TripleMazeGame.cs`：首页、游戏、结果、入槽与合并动画、撤回和输入缓冲。
- `PolishUI.cs`：圆角面板、按压回弹、浮动、音效与短振动。
- `PathSmoother.cs`：复用 ArrowSmash 的圆角路径算法。
- `TripleMazeLevelEditor.cs`：轻量网格工具、JSON 读写、颜色编辑、求解、试玩。
- `DemoSetup.cs`：场景创建与编辑器试玩数据传递。

## 与笔试交付的关系

笔试要求：核心 puzzle demo、首页/游戏页/结果页、手机至少 20 关、项目工程、实现总结。当前实现覆盖工程内的核心循环和 20 关数据；WebGL 导出和手机浏览器真机体验由后续交付阶段验证。本轮没有将关卡编辑器界面或技术实现说明放进玩家可见流程。

## 图片与难度驱动的关卡生成

主编辑器新增“图片 / 快速生成”和“难度报告”。支持本地图片尺寸、轮廓和主色识别，画笔/擦除/圈选轮廓，目标难度候选搜索，可解性重放，调色板随关卡保存，以及 JSON + 生成配方单张或批量导出。完整操作和指标定义见 `Docs/快速生成器说明.md`。
