# 图片、轮廓与难度驱动的关卡生成

入口：关卡编辑器顶部的“图片 / 快速生成”，或 Unity 菜单“TripleMaze > 图片与难度生成器”。已有手工关卡可以通过“难度报告”单独评估。

## 当前推荐：图片密铺模式

勾选“优先填满图片”。此模式不限制箭头数量，优先铺满有效轮廓并匹配原图色块，通过头尾朝向调整出口、遮挡层数和依赖关系。综合参考分数采用遮挡难度，三消压力仅作附加信息。参考箭身长度用于控制分段观感；主色上限默认六色，少色图片不强制补色或提亮。三消数量通过拆分路径和尽量少的改色配平，不再删除末尾箭头造成缺口。

正式 30 关已更新为密铺版，详见 [DenseCampaign30/README.md](DenseCampaign30/README.md)。下文关于目标箭头数、补色、双目标匹配和最大 60 枚的规则仅适用于关闭“优先填满图片”后的旧数量模式。新模式没有该数量上限，求解器也已支持超过 63 枚箭头。

## 三种输入

1. 本地 PNG/JPG，或拖入 Unity Texture2D。自动读取原图尺寸，按所选网格长边保持宽高比，采样轮廓与最多六个主色。识别后可调整颜色。
2. 直接选择矩形、椭圆、菱形或爱心轮廓，再用画笔涂色、擦掉格点。
3. 在画布上圈轮廓：拖动一圈后松开自动闭合；也可逐点点击并按 Enter 闭合。Esc 取消。可选择替换原遮罩或叠加轮廓，擦除可以挖洞。

自动背景支持边角背景、透明通道、白底或不剔除；背景容差用于处理近白或近背景色。深色描边可以选择剔除。这里把图片当作轮廓与色块模板，不做语义识别，也不恢复截图内原有的箭头路径。复杂照片建议先修正遮罩，清晰底色、透明底、平涂插画效果更稳定。

## 快速生成

1. 选择难度预设，再按需调整“箭头难度目标”和“三消压力目标”。
2. 设置箭头数、颜色数、槽位数、配色优先程度、覆盖率、随机种子和搜索数量。
3. 点击“按设置搜索可解候选”。搜索在编辑器更新循环中逐种子执行，可以停止并保留已有结果。
4. 点击候选看轮廓配色、箭头、难度报告与已验证解。绿色表示两个分数都进入目标容差；黄色明确表示目标未命中。
5. 点击“采用到关卡编辑器”，再编辑、保存或试玩。采用前不覆盖当前关卡。也可单独或批量导出候选 JSON 和 `.recipe.json`。

导出的候选库不会自动替换当前正式关卡。需要替换正式关卡时，在主编辑器采用后保存到对应 `Resources/Levels/level_XX.json`。生成配方保存格点遮罩、采样颜色、调色板、参数、种子、候选和报告，可再次打开复现。已有同名导出文件不会被静默覆盖。

## 难度参数

难度是启发式设计指标，不是经过真人标定的绝对等级。评分应结合试玩继续调整。

| 维度 | 参数 | 用途 |
|---|---|---|
| 箭头 | 初始可移出数量和占比 | 开局选择是否过多，出路是否显眼 |
| 箭头 | 平均 / 最大遮挡深度 | 需要依次解除多少层遮挡 |
| 箭头 | 平均遮挡者数量 | 一条箭头的出口依赖多少条其他箭头 |
| 箭头 | 平均转折数 | 视觉追踪与路径理解的负担 |
| 箭头 | 已知解中的平均可选数量 | 用于理解局面的分支，不单独证明难度 |
| 三消 | 颜色数与槽位容量 | 能否产生空间压力 |
| 三消 | 已验证通关解的槽位峰值 | 该路线实际需要多少剩余空间，属于已知解上界 |
| 三消 | 随机策略 / 优先凑色策略失败率 | 在固定种子下多次模拟选取，估计错误顺序的风险 |
| 三消 | 最小槽位峰值搜索 | 详细分析时逐级搜索，有预算；只有较低峰值全部被排除时才标“已证实最小” |
| 模板 | 覆盖率与配色误差 | 防止为了难度牺牲过多图形或颜色 |

箭头分数综合初始出口占比、遮挡深度、遮挡者数量和转折。三消分数综合空间余量、策略采样失败率和已知路线峰值。综合参考分数为 45% 箭头分数 + 55% 三消分数。生成按目标差距、配色误差、覆盖率与箭头数偏差排序。

一个关键约束：同色三枚立即消除后，每色最多剩两枚。因此七格收集槽只有一至三种颜色时永远不会因为槽满失败，这类关卡的三消压力必须记为零。需要四色以上，或减少槽位，才能产生相应压力。原图只有一两种颜色且不允许补色时，工具不会声称命中了高三消难度。

## 可解性与取舍

- 箭头在遮罩内部生成，不重叠、不越界、不跨过被擦除的格点。采用逆向构造：新箭头头部出口不能被已有箭头挡住，形成可逐步解除的依赖结构。
- 保证每色箭头数是三的倍数。配色尝试优先贴近原图，再进行保留数量的交换，寻找满足槽位限制的可行解。
- 每个交付候选都用实际 PuzzleModel 重放完整解，确认棋盘和收集槽最终同时清空。
- 难度目标不是无条件承诺。轮廓太细碎、颜色不够、格点不足或搜索预算不足时，可能只得到最近候选；工具保留真实分数并给出警告。
- 配色搜索未找到解时，可提供重新配色的保底候选，但明确标注配色调整和目标差距。
- “提高暗色可读性”会提高暗色亮度以适配当前深蓝棋盘；要求忠实原色时可以关闭。
- 最大目标 60 枚箭头、六种颜色；详细槽位搜索使用有界状态搜索，预算耗尽不等于无解。

## 复用来源

ArrowSmash 的 `ImageTemplateProcessor` 提供了图片采样、顶部为零的坐标与轮廓处理工作流；`ColorGradeDetector` 和 `ColorGrade` 的 Lab 聚类实现已适配到本项目编辑器。`ImageToLevelPipeline` 与 `StaticLevelBuilder` 的“模板 → 填充 → 校验 → 导出”结构用于新工具。三消配色、难度指标、逆向箭头构造与候选筛选针对 TripleMaze 单独实现，没有引入原项目的怪物、机关、广告或框架依赖。

## 验证与示例

2026-10-25 在 Unity 2022.3.62f3 验证：EditMode 29 项通过，PlayMode 7 项通过。覆盖图片比例与颜色、背景剔除、圈选遮罩、带孔轮廓、固定种子复现、遮挡环、槽位求解预算和实际规则重放；试玩检查包含滑出三消、胜负结算、撤回、重复点击和退出中断。
