# 开发备忘录

## 2026-10-25 通关后浮现关卡原图

### 设计目的

玩家清空棋盘并完成最后一组三消后，通过留下的格点逐渐还原生成关卡时使用的图片，让玩家看清自己刚刚解出的图案。

### 已实现行为

- 替换原来的通关格点波纹。
- 等待箭头飞出、入槽和三消动画全部完成后，才开始还原图片。
- 先用 0.45 秒将棋盘平滑恢复到默认缩放和居中位置。
- 用 2.6 秒让格点从中心向外逐渐展开为原图配色的小方块，随后叠入完整图片的细节，淡出方格层。
- 完整原图停留 1.6 秒后进入原有结算页。
- 展示期间关闭棋盘交互，避免拖动或缩放打断还原。
- 保留原图透明背景。没有底图的旧关卡、手绘关卡使用箭头配色形成方格图案。

### 图片数据与生成流程

- `LevelData.sourceImagePng` 保存 Base64 编码的 PNG，随关卡 JSON 一起携带，无需读取电脑上的原图片路径。
- `GenerationTemplate.sourceImagePng` 在生成配方中保存同一份图片，支持后续恢复、生成和导出。
- 导入图片时保留透明通道，最长边限制为 1024 像素；小图不放大。
- 普通生成和密铺生成两条流程均将图片传入关卡数据。
- 当前正式 30 关及 `Docs/BalancedCampaign30` 中的对应配方均已补入原图，包括进阶关卡对应的原图片。

### 主要代码位置

- `Assets/TripleMaze/Runtime/TripleMazeGame.cs`：通关动画顺序和停留时间。
- `Assets/TripleMaze/Runtime/ArrowBoardGraphic.cs`：`CompletionReveal` 进度、恢复全图视角和交互限制。
- `Assets/TripleMaze/Runtime/BoardDots.cs`：保留格点轮廓、采样原图颜色、方格展开、原图淡入及纹理释放。
- `Assets/TripleMaze/Runtime/PuzzleModel.cs`：关卡底图字段。
- `Assets/TripleMaze/Editor/Generation/GenerationData.cs`：配方底图字段。
- `Assets/TripleMaze/Editor/Generation/TemplateImageProcessor.cs`：图片采样、尺寸限制和 PNG 编码。
- `Assets/TripleMaze/Editor/Generation/QuickLevelGenerator.cs`、`DenseImageGenerator.cs`：将底图传入生成结果。
