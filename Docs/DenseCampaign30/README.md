# 图片密铺版 30 关

本套已替换正式 `Resources/Levels/level_01.json` 至 `level_30.json`，保留原来的图片主题和编号。

## 本轮规则

- 不设箭头数量目标或上限。先对原图 40×40 网格内的有效轮廓填充，箭头数量由色块、细节和参考箭身长度自然决定。
- 从外向内剥离并铺设路径，补齐可连接的末梢。数量不是三的倍数时拆分已有路径，不再删除箭头或挖空图片。
- 密度与难度分离。铺好路径后仅调整头尾朝向，拒绝会形成遮挡环的改动，通过初始出口、平均/最大遮挡深度和平均遮挡者数量接近目标难度。
- 对有效图片区域重新提取最多六个主色，保留白色和暗色。不为难度强行补充颜色，不统一提亮，不把多种颜色重刷成统一的粉彩色。
- 在一条几何可移出顺序上，用动态规划尽量减少改色，同时让每色数量为三的倍数并满足收集槽容量。保留生成时的完整可行序列。
- 综合参考分数使用遮挡难度；三消压力仍显示为附加信息，不再反过来削减密度或为凑压力重画原图颜色。

本套每关 96–204 枚箭头，平均 156.5 枚。平均有效格点覆盖率约 99.61%，最低约 98.28%，最高 100%。少量断开的单格装饰或不可连接的细末梢可能保留为空白；覆盖率按图片遮罩格点计算，不是线条的屏幕像素面积。

## 编辑与备份

生成器勾选“优先填满图片”即可使用新规则。调整“箭身参考长度”会改变线条分段和箭头数量，但不会作为难度分数。原图主色上限默认六色；少色原图不强制变成多色图。保留“收集槽容量”以继续支持三消。

每关 `.recipe.json` 可在生成器中打开。`30关清单.csv` 记录真实数量、填充率、遮挡指标和配色误差。`Staging` 是已导入 JSON 的副本，`../source-levels.json` 保存已知通关顺序和来源索引。

上一版稀疏 30 关已备份到 `Backups/ImageCampaign30_before_dense_20261025`。图片来自 Twemoji v14.0.2，作者 Twitter, Inc. and other contributors，CC BY 4.0。原始素材与完整许可位于工程旁的“关卡图片素材”目录；本套做了网格采样、箭头布局与少量三消配色配平。

按本轮要求只确认 Unity 编译，不运行 EditMode/PlayMode 测试或自动试玩。生成器自身仍保留结构校验和通关序列重放，避免导出明显损坏的数据；难度与实际操作体验由用户试玩评估。
