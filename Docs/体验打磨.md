# 视觉与操作体验改版

## 统一视觉

- 使用深蓝底色、低对比的棋盘卡片和薄荷绿主按钮，柔和但区分清楚的六色箭头。
- ArrowSmash 的 PathSmoother 直接移植到 TripleMaze 命名空间，箭头圆角与滑出使用同一套路径；正文保持开源中文字体，英文标题复用 Amaze GO 的 Inter Bold。
- 首页包含浮动的微型棋盘、三枚同色卡片和统一的按钮层次。游戏页重排导航、进度、棋盘、收集槽与操作区。结果页使用 Amaze GO 星星与缓动弹层。
- 面板改为 UGUI 程序化圆角网格，避免随意裁切九宫格带来的变形。按钮借鉴 ArrowSmash 的按压缩放和释放回弹，使用不依赖 DOTween 的轻量组件。

## 点击与消除反馈

- 按下箭头立即提亮与轻微加粗，命中范围适当扩大；放大与拖动仍以手机画布坐标计算。
- 可移出箭头沿自身圆角路径滑出，再转为同色卡片沿曲线飞入收集槽。槽中同色卡片会靠在一起，已有卡片顺滑让位。
- 每次入槽有短促的落点音和回弹。凑齐三枚后先保留完整的三枚视觉，再收拢、缩小、星点散开，剩余卡片补位。
- 连续三消会提升提示与轻微调整提示音音高；点击、滑出、落点、三消、提示、成功失败使用不同的原游戏音效。背景音乐以低音量循环，首页可以一键静音并保存。
- 被挡箭头短暂回弹，挡点亮起，不扣生命。动画中支持一次后续点击缓冲，重复点击同一枚不会重复结算。
- 增加可撤回操作。回到首页、重试和换关会取消未完成的飞行与消除，不遗留收集状态。
- Android 配置了短振动反馈和 VIBRATE 权限；WebGL 使用支持时才调用的 navigator.vibrate。当前未做浏览器或真机触觉验证。

## 关卡重新编排

原功能验证集已重新选择 ArrowSmash 的 Levels 与 LevelsHot 普通地图，仍不引入道具或特殊机关。地图只裁去既有可移出序列开头的一部分箭头，再重新配色。

前四关为 3、6、9、12 枚箭头，颜色数从 1、2、3 增加到 4。从第 4 关开始出现真正的七格空间压力：最多三种颜色时，自动三消后每色最多剩两枚，槽内最多六枚；因此必须引入第四种颜色，收集顺序才可能导致槽满。

之后逐步增加到 51 枚箭头和五种颜色，关卡名称和配色按递进节奏重新设置。每关都保存一条已知可通关序列，配色时限制该序列的槽位峰值不超过六枚。该保障表示存在可行解，并不表示任意操作顺序都能获胜。

`Docs/curate_levels.py` 为本轮编排脚本，`Docs/source-levels.json` 保存每关地图来源、数量、颜色数与通关序列。旧的 prepare_sources.py 是第一版提取脚本，不应用于覆盖本轮关卡。

## 资源追溯

具体图片和音效映射见 `Docs/polish-sources.json`。优先复用 Amaze GO 的图标、星星和音效；路径算法、按钮反馈依据及缺少的资源在 ArrowSmash 中查找。原始 ArrowSmash 工程保持只读。

## 首页背景、评价与结果页调整

首页保留标题图，移除独立主视觉，改为铺满屏幕的低对比箭头底纹。四个评价字图使用内置 image_gen 单独生成，提示词见 feedback-art-prompts.json；语音在先检查 Amaze GO 后，找到 ArrowSmash 的完整对应系列 sfx_combo_good/great/perfect/excellent.wav，统一复用该套语音，资源映射见 feedback-assets.json。

评价从收集栏中心上沿弹起，使用缩放回弹、轻微摆动、光晕、星点和上浮淡出，与语音同步。通关点阵从 1.05 秒放慢到 1.8 秒，再进入重做的独立全屏结果页。结果页使用皇冠、三颗依次弹出的星星、移动与三消数据卡片，以及主要/次要操作按钮。
