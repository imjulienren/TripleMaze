# TripleMaze

一款融合箭头解谜与同色三消的休闲益智游戏。点击箭头解开遮挡，将同色箭头凑成三枚消除，清空棋盘后揭晓完整图案。

核心玩法兼具策略与乐趣，操作顺畅跟手，动画与音效反馈清晰爽快。画面简洁精致，关卡图案美观，兼顾解谜挑战与视觉享受。

[在线试玩](https://imjulienren.github.io/TripleMaze/)

## 开发历程

从箭头解谜与同色三消的基础玩法出发，逐步完善首页、关卡与结算流程，再围绕图片轮廓和色彩反复调整，形成 30 个图案关卡。

开发中持续打磨连续点击、缩放拖动、箭头移动和三消手感，并完善碰撞、连击、音效与通关反馈，让操作更顺畅，画面更有表现力。

随后加入深浅主题和进度保存，搭建本地工作台，方便调整关卡、界面与声音。我负责设计方向与体验验收，AI 辅助实现与迭代。
