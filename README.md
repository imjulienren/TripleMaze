# TripleMaze

一款融合箭头解谜与同色三消的休闲益智游戏。点击箭头解开遮挡，将同色箭头凑成三枚消除，清空棋盘后揭晓完整图案。

核心玩法兼具策略与乐趣，操作顺畅跟手，动画与音效反馈清晰爽快。画面简洁精致，关卡图案美观，兼顾解谜挑战与视觉享受。

[在线试玩](https://imjulienren.github.io/TripleMaze/)

## 开发历程

### 早期版本（具体日期未留存）

- 将箭头解谜与同色三消结合：移出无遮挡箭头，在七格收集栏凑齐三个同色消除，完成首批 20 关和基础通关流程。
- 加入棋盘缩放、拖动、提示与撤回，适配手机竖屏；补充箭头移动、碰撞、消除和结算反馈。
- 从规则关卡转向图片关卡，扩充到 30 关。先提高铺满程度，让图案更完整；发现过密后再减少箭头，并合并容易混淆的近似色。
- 简化游戏界面，将收集栏移到棋盘上方；加入连续消除评价，通关后拉回全图、揭晓原图，失败不播放胜利礼花。

### 2026-10-25

- 箭头移动过快且越飞越快，改为匀速，速度从 55 调到 50 格/秒；增加拖尾，碰撞改为接触障碍后回弹。
- 连续操作需要等待上一支箭头，改为成功点击后立即释放通路，允许多支箭头同时离场。
- 箭头离场后再飞入收集栏显得拖沓，改为尖端触边时，收集栏直接弹出同色色块，保留三消反馈。
- 去掉可见棋盘底板和边框，只保留图案范围内的格点；减少静止画面的重复绘制，改善流畅度。
- 图片关卡先密铺到每关 96–204 支，再根据操作密度调整到 102–114 支；保留轮廓，不靠挖空图片减少数量，相近深浅色可互相消除。
- 失败统一显示三颗空星；当时采用每次启动从第 1 关开始的规则，后续改为保存进度。

### 2026-10-26

- 扩充至 50 关，每五关一个 HARD，按箭头数量和累计遮挡深度区分普通与困难关；游戏改为英文界面，换用 Nunito 字体，加入困难开场和难度标签。
- 发现关卡规模过大、短箭头偏多，回调到 30 关，扩大棋盘并优先保留长路径；普通关平均遮挡深度调整为 10–30，困难关增加规模与配色。
- 困难关出现太频繁，再改为第 10、20、30 关安排 HARD，空出的关卡换成普通卡通图；增加紫色 SUPER HARD，只有明确指定才启用。
- 图片方向从复杂风景转为主体清楚、色块分明的多彩卡通，兼顾图案辨识与颜色选择。
- 通关礼花改为双侧彩带，逐步调整数量、大小、轨迹与颜色浓度；播放时机提前到棋盘清空、原图揭晓阶段，其他界面平滑淡出，让注意力集中在图案上。
- 将胜利音效提前到礼花出现时播放，取消结算页重复响声；成功页王冠改为本关原图，失败页灯泡换成失落小星星，再补充星点与晃动装饰。
- 强化困难关开场的大字与横幅，增加 READY FOR THIS? 提示；调整设置面板和结算布局，关闭入口改为右上角红叉，重开与返回菜单横排。
- 深色箭头不易辨认，增加深浅主题切换和对比描边；提高浅色首页底图与格点可见度，取消格点内外轮廓差异，随后将首次启动默认改为浅色。
- 从每次重开首关改为保存闯关进度，再扩展为保存未完成局面、收集栏、生命和撤回记录；续玩不重播困难开场，失败或主动重开清除本局。
- 替换四段消除评价语音；连续消除加入 20 秒时限，同一对箭头仅首次碰撞扣生命，重复碰撞仍保留反馈。
- 评价触发调整为第 3、6、9、12 次对应 Good、Great、Perfect、Excellent，之后每三次随机出现 Excellent 或 Eagle；新增 Eagle 字图与语音，并分别调整评价大小。
- 三消从直接缩小消失改为弹起、合拢碰撞、碎成粒子，声音与震动在碰撞时触发；尝试破碎音后恢复原消除音，保留新动画。

### 2026-10-27

- 短箭头破坏路径感，明确常规箭头至少连续占四格，仅最终三消配平允许少量标记的三格，禁止两格；修正 30 关中的 448 支短箭头，保留选图、箭头数量和困难关节奏。
- 手机双指缩放不跟手，改为按双指张合比例缩放并跟随中点移动；双指操作期间屏蔽误点击，松开一根手指也不会误发射。
- 放大后棋盘被小窗口截断，扩大收集栏与底部按钮之间的显示及操作区域，同步放宽拖动范围。
- 关卡生成的颜色类别上限从八种提高到十二种，保留近似色合并与三消配平，不强行给图片补色。
- 目标箭头数与生成结果偏差过大，改为根据图案占格和数量调整路径长度，先尝试精确命中，再放宽到目标上下十五支；保持图案完整和最短长度规则。
- 关卡名称改用对应图片的英文名；HARD 与 SUPER HARD 标签独立调整位置，并统一不同主题下的文字配色。

### 2026-10-28

- 首次启动默认改回深色，保留玩家主动选择；桌面默认窗口调整为 720 × 1280，与游戏的 9:16 竖屏设计一致。
- 背景音乐替换为 3d_bgm.wav，按钮点击声替换为新的短音效。
- 多组三消不再排队等待，各组凑齐后可同时播放，结算仍等待全部动画结束。
- 评价触发次数改为可分别设置，并支持关闭与重复间隔；Eagle 改为明确次数触发，取消高连击时的随机替换。
- 困难开场过于花哨，改为红色或紫色柔软缎带，去掉光晕、轨道、徽记和副标题；加深背景遮罩，突出难度提示。
- 缎带中央展示从 1.2 秒逐步缩短至 0.8 秒，小难度标签也改为同款缎带；尝试缩小落位、绕圈和拉伸后，认为运动歪扭，最终改为大缎带平顺飞出右侧，再由小缎带从右侧滑回标签。
